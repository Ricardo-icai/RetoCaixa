## 1. EXECUTIVE DIRECTIVE & PRODUCT VISION

Act as a Senior Staff Software Architect and Full-Stack Engineer. Your objective is to build a mobile-first, production-oriented investment application for young users under the **CaixaBank / Imagin** ecosystem powered by **Google Cloud**[cite: 1, 2].

The application must make investing feel simple, natural, visual, trustworthy, modern, educational, and never intimidating[cite: 1, 2]. The user must interact with **one intelligent investment copilot** named **KAI**, hiding all internal multi-agent complexity[cite: 1, 2].

### Core Requirements & Hard Guardrails:
1. **Complex Backend, Simple Frontend:** Never expose internal agent names, orchestration graphs, raw scores, or technical compliance jargon[cite: 1, 2].
2. **Deterministic Financial Safety:** Financial limits, capacity checks, and risk scoring must be calculated using **deterministic TypeScript logic**, never unconstrained LLM outputs[cite: 1, 3].
3. **Protect Mode:** If emergency liquidity is below 3 months of essential expenses or high-cost debt exists, block investment recommendations and trigger **Protect Mode** (`BUFFER_REST_PROTECT`)[cite: 2, 3].
4. **Real-time News & Market Intelligence:** Ingest verified macroeconomic and sector news to update agent world-awareness without making false promises or predicting returns[cite: 1, 2].
