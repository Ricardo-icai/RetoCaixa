# 🚀 SYSTEM PROMPT: STOXIA SOCIAL GRAPH & CONCURRENCY

Role: Senior Backend Architect.
Goal: Implement a scalable social graph for Stoxia allowing users to follow creators and add friends.

Requirements:
1. Update Prisma Schema: Add a many-to-many self-relation `Follow` model on the `User` table to handle Followers and Following counts. Include database indexes (`@@index`) for rapid querying.
2. Next.js API Routes / Server Actions: Create optimized endpoints to `toggleFollowUser`, `getFollowers`, and `getSuggestedCreators`.
3. Optimistic UI Updates: In the React frontend, ensure the "Follow" button updates the UI instantly (optimistic rendering) before the server confirms the database write, ensuring a snappy, TikTok-like fluid experience.
